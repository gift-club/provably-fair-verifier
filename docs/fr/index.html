Vérificateur Provably fair

Vérifie n'importe quelle manche de Gift Club toi-même, sur ta propre machine, avec les mêmes maths que celles du serveur.

Une manche Provably fair, tout le monde peut la recalculer. Avant la manche, le serveur publie le hash SHA-256 d'un server seed secret ; après, le seed lui-même. Ce paquet compare le seed au hash et retire la manche avec HMAC-SHA256, pour que tu voies que le résultat était fixé avant ta partie et n'a pas été modifié après.

Vérifie une manche en quatre étapes

  1. Dans les détails de la manche dans Gift Club, copie le hash du server seed affiché avant ta partie.
  2. Une fois le seed renouvelé, copie le server seed révélé, ton client seed et le nonce de la manche.
  3. Lance le vérificateur : il contrôle que le SHA-256 du seed est égal au hash, puis retire les nombres de la manche.
  4. Compare le résultat recalculé à celui de ton historique. Ils correspondent octet pour octet.

En ligne de commande

Avec npx, rien à installer. L'exemple ci-dessous est la manche de démonstration du paquet lui-même :

npx @gift-club/provably-fair-verifier \

En bibliothèque

npm install @gift-club/provably-fair-verifier
import { generateFloats, hexToBytes, sha256Hex } from "@gift-club/provably-fair-verifier";

const seed = hexToBytes(serverSeed);
(await sha256Hex(seed)) === serverSeedHash;              // the seed was fixed before the round
const [f] = await generateFloats(seed, clientSeed, nonce, 1); // the round's first draw, in [0, 1)

Le tirage propre à chaque jeu (où tombe la bille, quelles cartes sont distribuées, le point de Crash) est un espace de noms, par exemple plinkoGold, crash ou collect. Types TypeScript inclus.

Chaque fonction reproduit une méthode du serveur octet pour octet, et les tests la rattachent à plus de 2 600 vecteurs entrée–sortie produits par le code du serveur lui-même. Si les maths du serveur changent, ces tests échouent jusqu'à ce que le vérificateur colle de nouveau.

Questions

Que veut dire Provably fair ?

Que n'importe qui peut prouver que le résultat d'une manche était fixé avant la mise et n'a pas été modifié après. Le serveur s'engage sur un seed secret en publiant son hash, mélange un seed que tu contrôles, puis révèle le sien plus tard pour que tu puisses recalculer le résultat.

Le serveur peut-il changer un résultat après ma partie ?

Pas sans se faire prendre : un autre seed donne un autre hash SHA-256, et le hash t'a été montré avant la manche.

Pourquoi mon client seed compte-t-il ?

Le résultat dépend des deux seeds. Comme tu peux définir ton propre client seed, le serveur ne peut pas choisir un seed qui favorise un résultat connu d'avance.

Le vérificateur a-t-il besoin d'internet ou d'un compte ?

Non. Il tourne entièrement sur ta machine et n'a besoin que des quatre valeurs de la manche.
