Provably fair verifier

Check any Gift Club round yourself, on your own machine, with the same maths the server ran.

A provably fair round can be re-computed by anyone. Before the round the server publishes the SHA-256 hash of a secret server seed; after it, the seed itself. This package checks the seed against the hash and re-draws the round with HMAC-SHA256, so you can see that the result was fixed before you played and was not changed after.

Verify a round in four steps

  1. In the round's details in Gift Club, copy the server seed hash shown before you played.
  2. After the seed rotates, copy the revealed server seed, your client seed and the round's nonce.
  3. Run the verifier: it checks that SHA-256 of the seed equals the hash, then re-draws the round's numbers.
  4. Compare the re-drawn result with the one in your history. They match byte for byte.

From the command line

No install needed with npx. The example below is the package's own demo round:

npx @gift-club/provably-fair-verifier \

As a library

npm install @gift-club/provably-fair-verifier
import { generateFloats, hexToBytes, sha256Hex } from "@gift-club/provably-fair-verifier";

const seed = hexToBytes(serverSeed);
(await sha256Hex(seed)) === serverSeedHash;              // the seed was fixed before the round
const [f] = await generateFloats(seed, clientSeed, nonce, 1); // the round's first draw, in [0, 1)

Each game's own draw (where the ball lands, which cards are dealt, the crash point) is a namespace, e.g. plinkoGold, crash or collect. TypeScript types included.

Why you can trust the code

Every function mirrors a server method byte for byte, and the tests pin it to more than 2,600 input–output vectors produced by the server's own code. If the server's maths ever changes, these tests fail until the verifier matches again.

Questions

What does provably fair mean?

That anyone can prove a round's result was fixed before the bet and not changed after. The server commits to a secret seed by publishing its hash, mixes in a seed you control, and reveals its seed later so you can re-compute the result.

Can the server change a result after I play?

Not without being caught: a different seed gives a different SHA-256 hash, and the hash was shown to you before the round.

Why does my client seed matter?

The result depends on both seeds. Since you can set your own client seed, the server cannot pick a seed that favours a known outcome for you.

Does the verifier need an internet connection or an account?

No. It runs entirely on your machine and needs only the four values from the round.
