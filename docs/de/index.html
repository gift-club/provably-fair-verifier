Provably-fair-Verifier

Prüfe jede Gift-Club-Runde selbst, auf deinem eigenen Rechner, mit derselben Mathematik, die der Server ausgeführt hat.

Eine Provably-fair-Runde kann jeder neu berechnen. Vor der Runde veröffentlicht der Server den SHA-256-Hash eines geheimen Server Seeds, danach den Seed selbst. Dieses Paket gleicht den Seed mit dem Hash ab und zieht die Runde mit HMAC-SHA256 neu, sodass du siehst: Das Ergebnis stand fest, bevor du gespielt hast, und wurde danach nicht geändert.

Eine Runde in vier Schritten prüfen

  1. Kopiere in den Rundendetails in Gift Club den Server-Seed-Hash, der vor deinem Spiel angezeigt wurde.
  2. Kopiere nach dem Seed-Wechsel den offengelegten Server Seed, deinen Client Seed und den Nonce der Runde.
  3. Starte den Verifier: Er prüft, ob der SHA-256 des Seeds dem Hash entspricht, und zieht dann die Zahlen der Runde neu.
  4. Vergleiche das neu gezogene Ergebnis mit dem in deinem Verlauf. Sie stimmen Byte für Byte überein.

Als Bibliothek

npm install @gift-club/provably-fair-verifier
import { generateFloats, hexToBytes, sha256Hex } from "@gift-club/provably-fair-verifier";

const seed = hexToBytes(serverSeed);
(await sha256Hex(seed)) === serverSeedHash;              // the seed was fixed before the round
const [f] = await generateFloats(seed, clientSeed, nonce, 1); // the round's first draw, in [0, 1)

Die Ziehung jedes Spiels (wo die Kugel landet, welche Karten ausgeteilt werden, der Crash-Punkt) ist ein Namespace, z. B. plinkoGold, crash oder collect. TypeScript-Typen sind enthalten.

Warum du dem Code vertrauen kannst

Jede Funktion bildet eine Server-Methode Byte für Byte nach, und die Tests binden sie an mehr als 2.600 Eingabe-Ausgabe-Vektoren, die der Servercode selbst erzeugt hat. Ändert sich die Mathematik des Servers, schlagen diese Tests fehl, bis der Verifier wieder passt.

Fragen

Was bedeutet Provably fair?

Dass jeder beweisen kann, dass das Ergebnis einer Runde vor dem Einsatz feststand und danach nicht geändert wurde. Der Server legt sich auf einen geheimen Seed fest, indem er dessen Hash veröffentlicht, mischt einen Seed ein, den du bestimmst, und legt seinen Seed später offen, damit du das Ergebnis neu berechnen kannst.

Kann der Server ein Ergebnis ändern, nachdem ich gespielt habe?

Nicht, ohne erwischt zu werden: Ein anderer Seed ergibt einen anderen SHA-256-Hash, und den Hash hat man dir vor der Runde gezeigt.

Warum ist mein Client Seed wichtig?

Das Ergebnis hängt von beiden Seeds ab. Weil du deinen Client Seed selbst setzen kannst, kann der Server keinen Seed wählen, der ein bekanntes Ergebnis begünstigt.

Braucht der Verifier eine Internetverbindung oder ein Konto?

Nein. Er läuft komplett auf deinem Rechner und braucht nur die vier Werte der Runde.
