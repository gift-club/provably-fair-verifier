Verificatore Provably fair

Controlla qualsiasi round di Gift Club in autonomia, sul tuo computer, con la stessa matematica che ha eseguito il server.

Un round Provably fair può essere ricalcolato da chiunque. Prima del round il server pubblica l'hash SHA-256 di un server seed segreto; dopo, il seed stesso. Questo pacchetto confronta il seed con l'hash e rigenera il round con HMAC-SHA256, così vedi che il risultato era fissato prima che giocassi e non è stato cambiato dopo.

Verifica un round in quattro passi

  1. Nei dettagli del round in Gift Club, copia l'hash del server seed mostrato prima di giocare.
  2. Dopo la rotazione del seed, copia il server seed rivelato, il tuo client seed e il nonce del round.
  3. Esegui il verificatore: controlla che lo SHA-256 del seed sia uguale all'hash, poi rigenera i numeri del round.
  4. Confronta il risultato rigenerato con quello nella tua cronologia. Coincidono byte per byte.

Come libreria

npm install @gift-club/provably-fair-verifier
import { generateFloats, hexToBytes, sha256Hex } from "@gift-club/provably-fair-verifier";

const seed = hexToBytes(serverSeed);
(await sha256Hex(seed)) === serverSeedHash;              // the seed was fixed before the round
const [f] = await generateFloats(seed, clientSeed, nonce, 1); // the round's first draw, in [0, 1)

L'estrazione di ogni gioco (dove cade la pallina, quali carte vengono date, il punto di Crash) è un namespace, per esempio plinkoGold, crash o collect. Tipi TypeScript inclusi.

Perché puoi fidarti del codice

Ogni funzione replica un metodo del server byte per byte, e i test la legano a più di 2.600 vettori di input e output prodotti dal codice del server stesso. Se la matematica del server cambia, questi test falliscono finché il verificatore non torna a coincidere.

Domande

Cosa significa Provably fair?

Che chiunque può dimostrare che il risultato di un round era fissato prima della puntata e non è stato cambiato dopo. Il server si impegna su un seed segreto pubblicandone l'hash, mescola un seed che controlli tu e rivela il proprio più tardi, così puoi ricalcolare il risultato.

Il server può cambiare un risultato dopo che ho giocato?

Non senza essere scoperto: un seed diverso dà un hash SHA-256 diverso, e l'hash ti è stato mostrato prima del round.

Perché il mio client seed conta?

Il risultato dipende da entrambi i seed. Dato che puoi impostare tu il tuo client seed, il server non può scegliere un seed che favorisca un esito già noto.

Il verificatore ha bisogno di internet o di un account?

No. Funziona interamente sul tuo computer e servono solo i quattro valori del round.
