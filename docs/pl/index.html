Weryfikator Provably fair

Sprawdź dowolną rundę Gift Club na własnym komputerze, tą samą matematyką, którą wykonał serwer.

Rundę Provably fair może przeliczyć każdy. Przed rundą serwer publikuje hash SHA-256 tajnego server seed, a po niej sam seed. Ten pakiet sprawdza seed z hashem i losuje rundę od nowa przez HMAC-SHA256, więc widać, że wynik był ustalony przed grą i nie zmieniono go potem.

Zweryfikuj rundę w czterech krokach

  1. W szczegółach rundy w Gift Club skopiuj hash server seed pokazany przed grą.
  2. Gdy seed się zmieni, skopiuj ujawniony server seed, swój client seed i nonce rundy.
  3. Uruchom weryfikator: sprawdzi, że SHA-256 seeda równa się hashowi, i wylosuje liczby rundy od nowa.
  4. Porównaj przeliczony wynik z tym z historii. Zgadzają się co do bajta.

Jako biblioteka

npm install @gift-club/provably-fair-verifier
import { generateFloats, hexToBytes, sha256Hex } from "@gift-club/provably-fair-verifier";

const seed = hexToBytes(serverSeed);
(await sha256Hex(seed)) === serverSeedHash;              // the seed was fixed before the round
const [f] = await generateFloats(seed, clientSeed, nonce, 1); // the round's first draw, in [0, 1)

Losowanie każdej gry (gdzie spadnie kulka, jakie karty rozdano, punkt Crash) to osobna przestrzeń nazw, np. plinkoGold, crash lub collect. Typy TypeScript w komplecie.

Pytania

Co znaczy Provably fair?

Że każdy może udowodnić, że wynik rundy był ustalony przed zakładem i nie zmieniono go potem. Serwer zobowiązuje się do tajnego seeda, publikując jego hash, miesza seed, który ustawiasz ty, a swój seed ujawnia później, żeby można było przeliczyć wynik.

Czy serwer może zmienić wynik po mojej grze?

Nie tak, żeby nie wyszło to na jaw: inny seed daje inny hash SHA-256, a hash pokazano ci przed rundą.

Dlaczego mój client seed ma znaczenie?

Wynik zależy od obu seedów. Ponieważ własny client seed można ustawić samodzielnie, serwer nie może wybrać seeda sprzyjającego znanemu mu wynikowi.

Czy weryfikator potrzebuje internetu albo konta?

Nie. Działa w całości na twoim komputerze i potrzebuje tylko czterech wartości z rundy.
