Verificador Provably fair

Comprueba cualquier ronda de Gift Club por tu cuenta, en tu propio equipo, con las mismas matemáticas que ejecutó el servidor.

Una ronda Provably fair puede recalcularla cualquiera. Antes de la ronda el servidor publica el hash SHA-256 de un server seed secreto; después, el propio seed. Este paquete comprueba el seed contra el hash y vuelve a sortear la ronda con HMAC-SHA256, así que ves que el resultado quedó fijado antes de que jugaras y no se cambió después.

Verifica una ronda en cuatro pasos

  1. En los detalles de la ronda en Gift Club, copia el hash del server seed que se mostró antes de jugar.
  2. Cuando el seed rota, copia el server seed revelado, tu client seed y el nonce de la ronda.
  3. Ejecuta el verificador: comprueba que el SHA-256 del seed coincide con el hash y vuelve a sortear los números de la ronda.
  4. Compara el resultado recalculado con el de tu historial. Coinciden byte a byte.

Como librería

npm install @gift-club/provably-fair-verifier
import { generateFloats, hexToBytes, sha256Hex } from "@gift-club/provably-fair-verifier";

const seed = hexToBytes(serverSeed);
(await sha256Hex(seed)) === serverSeedHash;              // the seed was fixed before the round
const [f] = await generateFloats(seed, clientSeed, nonce, 1); // the round's first draw, in [0, 1)

El sorteo de cada juego (dónde cae la bola, qué cartas se reparten, el punto de Crash) es un espacio de nombres, por ejemplo plinkoGold, crash o collect. Incluye tipos de TypeScript.

Cajas y rasca y gana

Las cajas y los rasca y gana sortean de una tabla fija de boletos: el verificador recalcula qué boleto eligió un sorteo, incluido un sorteo con objetivo fijado.

Por qué puedes fiarte del código

Cada función replica un método del servidor byte a byte, y las pruebas la fijan a más de 2600 vectores de entrada y salida generados por el código del propio servidor. Si las matemáticas del servidor cambian, esas pruebas fallan hasta que el verificador vuelva a coincidir.

Preguntas

¿Qué significa Provably fair?

Que cualquiera puede demostrar que el resultado de una ronda quedó fijado antes de la apuesta y no se cambió después. El servidor se compromete con un seed secreto publicando su hash, mezcla un seed que controlas tú y revela el suyo más tarde para que puedas recalcular el resultado.

¿Puede el servidor cambiar un resultado después de que juegue?

No sin que lo pillen: otro seed da otro hash SHA-256, y el hash te lo mostraron antes de la ronda.

¿Por qué importa mi client seed?

El resultado depende de los dos seeds. Como puedes fijar tu propio client seed, el servidor no puede elegir un seed que favorezca un resultado que ya conoce.

¿El verificador necesita conexión a internet o una cuenta?

No. Funciona por completo en tu equipo y solo necesita los cuatro valores de la ronda.
